# Learn Finance with AI

Website: https://ianding1.github.io/learn-finance-with-ai/ · [简体中文说明](README.zh-CN.md)

An economics and finance course written by AI, set in the US market. The course teaches you to:

1. Analyze firms and markets like an economist: how competition, incentives and asymmetric information shape prices and profits.
2. Explain how interest rates, inflation, the business cycle and monetary policy move the prices of different assets.
3. Read financial statements and value bonds and stocks.
4. Explain why diversification works, why risk and expected return are linked, and why most actively managed funds trail their index.
5. Understand what it takes to build a portfolio for a US household, including accounts and taxes, asset allocation and retirement withdrawals.

The site is fully static and never calls an AI. For grading and explanations it builds a prompt that
learners paste into their own AI assistant.

> **Important**: all lessons, questions and reference answers were generated by AI and have not been
> reviewed by a professional. Their correctness is not guaranteed. The content is for learning only
> and is not investment advice.

## Contributing

Contributions are welcome, especially:

- **Corrections.** If you find an error, [open an issue](https://github.com/ianding1/learn-finance-with-ai/issues/new?labels=content-error)
  (every page has a "Report an error" link) or send a pull request with the fix.
- **New languages.** See [Adding a language](#adding-a-language).

All languages have the same status. When you change one language version of a page or text field,
`npm run check` lists the other languages that still need the same change. If you can only update
some of them, open the pull request anyway and say which languages are missing.

Two layers of checks keep the content consistent:

1. `scripts/check.py` (must pass before merging): all language versions present and in sync,
   references point to existing targets, concept order, questions match answers, numeric answers
   recomputed, slider parameters valid, and more.
2. An AI review (advisory) of what a script cannot judge, following `.github/review-rules.md`.

How lessons are written and published is described in [CLAUDE.md](CLAUDE.md).

## Development

Requirements: Node.js 20.3 or later, Python 3 with PyYAML.

```bash
npm install
npm run dev          # local preview at http://localhost:4321/learn-finance-with-ai/
npm run build        # production build
npm run check        # consistency checks (python3 scripts/check.py)
npm run i18n:lock    # record that all language versions are in sync (see below)
```

| Path | What it is |
| --- | --- |
| `src/i18n/languages.json` | The languages of the site |
| `src/i18n/locales/<code>.ts` | UI strings and prompt templates of one language |
| `src/content/docs/<code>/` | Pages of one language |
| `course/` | Curriculum, concepts, answer keys, numeric checks and widget settings (text in every language) |
| `src/components/`, `src/scripts/` | Components, interactive figures and browser code |
| `scripts/check.py` | Consistency checks run in CI |

### Translation lock

`course/translation-lock.json` stores a hash of every language version of every page and text field,
taken when the versions were last in sync. `npm run check` fails when some language versions of an
item changed and others did not, and names the languages to update. After all versions say the same
thing again, run `npm run i18n:lock`.

### Adding a language

1. Add the language to `src/i18n/languages.json` (`code` is used in folder names, URLs and YAML keys;
   `lang` is the BCP-47 tag, for example `zh-TW`).
2. Copy `src/i18n/locales/en.ts` to `src/i18n/locales/<code>.ts` and translate it.
3. Add the pages under `src/content/docs/<code>/`, with the same file names as the other languages.
4. Add a `<code>:` entry next to the existing languages in `course/curriculum.yaml`,
   `course/concepts.yaml`, `course/keys/*.yaml` and the label tables in `src/components/widgets/`.
5. Run `npm run check`, which lists everything that is still missing, then `npm run i18n:lock`.
