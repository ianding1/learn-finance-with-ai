# 跟 AI 学金融 · Learn Finance with AI

网站 / Website: https://ianding1.github.io/learn-finance-with-ai/

[English](#english)

一门由 AI 编写的经济学与金融课程，目标是高年级本科水平（中级微观、中级宏观、投资学、公司金融），以美国市场为背景，最终能为美国家庭建立投资组合模型。

> **重要说明**：本课程所有课件、题目和参考答案都由 AI 生成，未经专业人员审核，无法保证正确。内容仅用于学习，不构成投资建议。发现错误请[提交 issue](https://github.com/ianding1/learn-finance-with-ai/issues/new?labels=content-error)。

## 怎样学习

网站是纯静态的，本身不调用任何 AI，也不收集数据。

- **阅读**：每一课有讲解、推导和互动图。选中看不懂的文字，点击"展开讲解"，网站会生成一个讲解提示词。
- **练习**：在纸上写完随堂题（随讲解出现）和练习题（每课结尾）后，复制网站生成的提示词，连同答案照片一起发给你自己的 AI 助手（Claude、ChatGPT、Gemini 等），由 AI 批改，不计分。每学完一组课程有一次计分的测验。每课开头可以复制个性化的复习提示词，按你需要多练习的概念出题。
- **记录**：把 AI 返回的结果块粘贴回网站，得分和需要多练习的概念只保存在你的浏览器中。评卷提示词不包含学习档案；讲解提示词只附上相关的部分，可以关闭。

## 参与贡献

课程内容的一致性由两层检查保证：

1. `scripts/check.py`（必须通过才能合并）：多语言同步、引用目标存在、概念顺序、题目与答案对应、数值验算、互动图参数等。
2. AI 审查（只给建议）：按 `.github/review-rules.md` 检查脚本判断不了的语义问题。

编写和发布课程的流程见 [CLAUDE.md](CLAUDE.md)。

```bash
npm install
npm run dev
npm run check     # 需要 Python 3 和 PyYAML
```

## English

An economics and finance course written by AI, at the level of an upper-undergraduate economics
student (intermediate microeconomics, intermediate macroeconomics, investments and corporate
finance). It is set in the US market, and its final goal is to build portfolio models for US households.

> **Important**: all lessons, questions and reference answers in this course were generated by AI
> and have not been reviewed by a professional. Their correctness is not guaranteed. The content is
> for learning only and is not investment advice. If you find an error, please
> [open an issue](https://github.com/ianding1/learn-finance-with-ai/issues/new?labels=content-error).

### How to study

The website is fully static. It does not call any AI and does not collect data.

- **Read**: each lesson has explanations, derivations and interactive figures. Select text you do
  not understand and click "Explain this" to get an explanation prompt.
- **Practice**: write your answers to the check questions (within the lesson) and the
  exercises (at the end of the lesson) on paper, then copy the prompt the site
  generates and send it with a photo of your answers to your own AI assistant (Claude, ChatGPT,
  Gemini or another one). The AI reviews your answers without scores. A scored quiz follows each
  group of lessons. At the start of each lesson
  you can copy a personalized review prompt built from the concepts you need to practice.
- **Track**: paste the result block from the AI back into the site. Scores and the concepts to
  practice are saved only in your browser. Grading prompts never include the profile; explanation
  prompts include only the relevant part, and this can be turned off.

### Contributing

Two layers of checks keep the content consistent:

1. `scripts/check.py` (must pass before merging): language versions in sync, references point to
   existing targets, concept order, questions match answers, numeric answers verified, slider
   parameters valid, and more.
2. AI review (advisory): checks meaning that a script cannot judge, following `.github/review-rules.md`.

See [CLAUDE.md](CLAUDE.md) for how lessons are written and published.
