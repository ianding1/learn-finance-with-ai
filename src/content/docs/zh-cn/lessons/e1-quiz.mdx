## 公式表 [#formulas]

**消费者**

- 边际替代率：$MRS = \frac{MU_x}{MU_y}$

**跨期选择与不确定性**

- Fisher 方程：$1 + r = \frac{1 + i}{1 + \pi}$
- 期望效用：$E[u(W)] = \sum_i p_i\,u(W_i)$；确定性等价：$u(\text{CE}) = E[u(W)]$；风险溢价：$E[W] - \text{CE} \approx \frac12 A(W)\,\sigma^2$
- CRRA 效用（相对风险厌恶系数 $\gamma$）：按比例的风险溢价 $\approx \frac12\gamma\sigma^2$

**税收**

- 对每单位征税 $t$：买方付的价格 $P_b$ 与卖方得到的价格 $P_s$ 满足 $P_s = P_b - t$

**现值**

- 永续年金：$PV = \frac{C}{r}$；增长永续年金：$PV = \frac{C}{r - g}$（$C$ 为第 1 期期末的付款）
- $1 + \delta + \delta^2 + \cdots = \frac{1}{1 - \delta}$（$0 < \delta < 1$）
