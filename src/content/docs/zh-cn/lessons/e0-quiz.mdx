## 公式表 [#formulas]

**货币时间价值**

- 终值与现值：$FV = PV(1+r)^n$，$PV = \frac{FV}{(1+r)^n}$；有效年利率：$\text{EAR} = \left(1 + \frac{r}{m}\right)^m - 1$
- 年金（期末付款）：$PV = \frac{C}{r}\left[1 - (1+r)^{-n}\right]$，$FV = C\,\frac{(1+r)^n - 1}{r}$
- 永续年金：$PV = \frac{C}{r}$；增长永续年金：$PV = \frac{C}{r - g}$（$C$ 为第 1 期期末的付款）
- 对数收益率：$r = \ln(1 + R)$

**优化**

- 一阶条件：$f'(x^*) = 0$；二阶条件：$f''(x^*) < 0$ 为最大值，$f''(x^*) > 0$ 为最小值
- 拉格朗日函数：$\mathcal{L} = U(x, y) + \lambda\,(M - p_x x - p_y y)$

**概率与组合**

- $E[R] = \sum_i p_i R_i$，$\text{Var}(R) = \sum_i p_i (R_i - E[R])^2$，$\rho = \frac{\text{Cov}(R_A, R_B)}{\sigma_A \sigma_B}$
- 两资产组合：$\sigma_P^2 = w^2\sigma_A^2 + (1-w)^2\sigma_B^2 + 2w(1-w)\rho\,\sigma_A\sigma_B$

**统计推断**

- 样本标准差：$s = \sqrt{\frac{1}{n-1}\sum_t (R_t - \bar R)^2}$；标准误：$\text{SE}(\bar R) = \frac{s}{\sqrt{n}}$
- 95% 置信区间：$\bar R \pm 1.96\,\text{SE}$；$t = \frac{\bar R}{\text{SE}}$
- 标准化：$z = \frac{x - \mu}{\sigma}$；若 $\ln W$ 服从 $N(m, s^2)$，则 $W$ 的中位数为 $e^m$，均值为 $e^{m + s^2/2}$

**回归**

- $b = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2}$，$a = \bar y - b\,\bar x$，$R^2 = 1 - \frac{\text{SSR}}{\text{SST}}$
- 遗漏变量：只用 $x_1$ 回归时，斜率接近 $\beta_1 + \beta_2 \cdot \frac{\text{Cov}(x_1, x_2)}{\text{Var}(x_1)}$
