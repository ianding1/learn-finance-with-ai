## Formula sheet [#formulas]

**Time value of money**

- Future and present value: $FV = PV(1+r)^n$, $PV = \frac{FV}{(1+r)^n}$; effective annual rate: $\text{EAR} = \left(1 + \frac{r}{m}\right)^m - 1$
- Annuity (payments at the end of each period): $PV = \frac{C}{r}\left[1 - (1+r)^{-n}\right]$, $FV = C\,\frac{(1+r)^n - 1}{r}$
- Perpetuity: $PV = \frac{C}{r}$; growing perpetuity: $PV = \frac{C}{r - g}$ ($C$ is the payment at the end of the first period)
- Log return: $r = \ln(1 + R)$

**Optimization**

- First-order condition: $f'(x^*) = 0$; second-order condition: $f''(x^*) < 0$ for a maximum, $f''(x^*) > 0$ for a minimum
- Lagrangian: $\mathcal{L} = U(x, y) + \lambda\,(M - p_x x - p_y y)$

**Probability and portfolios**

- $E[R] = \sum_i p_i R_i$, $\text{Var}(R) = \sum_i p_i (R_i - E[R])^2$, $\rho = \frac{\text{Cov}(R_A, R_B)}{\sigma_A \sigma_B}$
- Two-asset portfolio: $\sigma_P^2 = w^2\sigma_A^2 + (1-w)^2\sigma_B^2 + 2w(1-w)\rho\,\sigma_A\sigma_B$

**Statistical inference**

- Sample standard deviation: $s = \sqrt{\frac{1}{n-1}\sum_t (R_t - \bar R)^2}$; standard error: $\text{SE}(\bar R) = \frac{s}{\sqrt{n}}$
- 95% confidence interval: $\bar R \pm 1.96\,\text{SE}$; $t = \frac{\bar R}{\text{SE}}$

**Regression**

- $b = \frac{\sum_i (x_i - \bar x)(y_i - \bar y)}{\sum_i (x_i - \bar x)^2}$, $a = \bar y - b\,\bar x$, $R^2 = 1 - \frac{\text{SSR}}{\text{SST}}$
